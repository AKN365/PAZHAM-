# Project Description
A program that calculates the curvature of a banana and plots its graph, and also rates it based on its curviness.

# The Problem (that doesn't exist)
Our inquisitive mind wondering how curved a banana is

# The Solution (that nobody asked for)
Our program calculates the curvature of a banana, prints its polynomial equation, plots its graph and rates it based on its curviness.

# Technical Details
-Processes image using OpenCV
-detects its contour
-extracts centre-line
-mathematical analysis of curve
-web interface for an interactive UI

# Technologies/Components Used
Languages: TypeScript, Python, CSS
Frameworks: Next.js, React
Libraries: OpenCV, NumPy, Motion
Tools: Git, GitHub, npm, VS Code, Vercel, Render

# Implementation
For Software:Developed a Next.js/React application using TypeScript for image upload and visualization, with Python, OpenCV and NumPy for banana detection and image processing. The system extracts the banana’s centreline, fits a polynomial curve, and calculates its equation and curvature.
